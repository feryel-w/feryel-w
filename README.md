### 👋 Hi, I'm Feryel

I'm a full-stack developer based in Tunisia. I like building complete products end to end: the backend, the interface, and lately the ML model and the infrastructure that runs it.

I've shipped web apps in Django, React, Next.js and Angular, mobile apps in Flutter, and AI projects that go past the notebook — like a sign-language recognition API packaged with Docker and Kubernetes.

- 🔭 **Currently building:** a log-monitoring SaaS on the ELK stack (Elasticsearch, Logstash, Kibana) with Django, MongoDB and Redis
- 🌱 **Learning:** MLOps — getting ML models from a notebook into Docker, Kubernetes and CI/CD
- 💼 **Available for:** freelance web projects (business sites, dashboards, internal tools, APIs) and remote roles
- 🗣️ **Languages:** Arabic · French · English
